# 短い速報の生成と SNS 動画の試作（2026-11-01 JST）

## 目的と変更

文字数を埋めるための水増しを防ぎ、短くても有益な Web 発表・報道の記事を作れるようにする。既存記事、広告、投稿履歴、SNS 予約、配信上限には触れない。

- `web_articles.py`: 記事データ作成時の 800 字以上という足切りを削除し、空本文は引き続き拒否。AI・幅広い話題・トレンド記事の生成指示から本文 1800〜5000 字やかんたん版 700〜1300 字の目標を除き、必要な条件・背景を保つよう指示。字数不足だけを理由とする追記処理を削除。事実に基づく編集部の見方は事実と区別して許可する。
- `quality.py`: Web 速報生成時の本文 1800 / 2500 字、主要ニュースでの 8 割、かんたん版 400 字と、指定見出し・表または特定の節 150 字という形式的条件を削除。空文・英語残骸・丸写しなどは維持。事実確認と同じ 1 回の LLM 呼び出しに、見出しへの回答と情報の具体性を確認する `useful` を追加。不足や応答欠落時は不合格。速報の外科的修正によって有用性不合格を迂回できない。文章を読みやすく直す処理は元の情報量を 90% 以上保つ条件を残し、絶対文字数の下限は外す。
- `main.py`: Web 生成にも共有される共通指示から、指定文字数に達しない原稿は不合格という矛盾した記述を削除。
- 品質判定 LLM の出力は誤判定しうる。自動確認は編集者の事実確認を保証しない。一次資料が空、モデルが利用不可、有用性の値が欠落したときは不合格。モデル利用料金は事業者の契約・従量条件に従う。確認の API 回数を通常時に増やす変更ではないが、回答失敗時の既存リトライは発生しうる。
- **範囲**: 動画原典の記事 `main.py` 独自の 4000〜6000 字・各節 400 字以上という生成指示は残存。動画本編に対する別の事実確認工程が Web と同等ではなく、安全に撤去するには別の検証が必要。ニュース検索の `is_indexable` と無関係な配信選定 `is_distribution_eligible` に 2000 字基準があり、週刊・朝まとめ等に影響するため本件では保持。検索エンジンへの IndexNow 対象は `is_indexable` を使う。PR 配信社の除外および明示 `indexable` は既存どおり。
- 公式方針: https://developers.google.com/search/docs/fundamentals/seo-starter-guide によると文字数だけで順位は決まらない。公開、Google の取得・登録、検索表示、検索クリックはそれぞれ別の段階。成果は未検証。

## 検証

`tests/test_article_quality_short.py` にて、800 字未満のレコード作成、2000 字未満本文・400 字未満のかんたん版の有用性確認後の受理、不足・事実不一致・判定欠落・判定不能・空本文の拒否、速報の緩和経路による迂回防止、既存の fact_check 呼び出し互換を外部 API を呼ばず検査。LLM の実応答や新規記事の本番作成の確認ではない。`test_evergreen_editorial.py`、`test_indexnow.py` も回帰確認。TypeScript と読みやすさは確認。標準 Turbopack build はローカル環境で port bind が拒否されたため失敗、代わりに `npx next build --webpack` は成功。デプロイ後は通常の定期記事生成の実行履歴で新しい `useful` が返り、合格・不合格と実行本数が異常でないかを確認する。投稿を増やすためにワークフローを手動実行しない。

## 動画方針（投稿・予約していない）

Meta は Threads で、文章を添えた動画が平均でより多く見られる傾向を紹介しているが、サイソクの記事流入増は未検証: https://about.fb.com/news/2024/10/find-your-community-with-new-threads-educational-insights/ 。現時点の Threads インサイト画面（対象期間は表示上 10/1〜10/30）では閲覧数 4,795、閲覧者 3,362。リストには 10/31 朝まとめ 282、KDDI 事例 228 と表示されるが、これらは媒体ごとの閲覧数で、記事への訪問数ではない。動画との比較検証はしていない。

試作は Meta 日本公式発表 https://about.fb.com/ja/news/2026/10/muse-personal-ai-agent-launches-in-japan/ を基にした 16 秒、720x1280 の無音・文字主体。外部動画や画像・音声・音楽は使っていない。Noto Sans JP の既存 OFL フォントを使用。試作の作成だけで、SNS 投稿・予約はしていない。比較するなら同じ媒体・近い話題・時間帯で画像投稿と動画投稿を各 8 件程度から始め、24 時間・72 時間の表示、動画視聴、リンククリック、UTM付きのサイト訪問を別々に記録。小標本のため差は仮説として扱う。効果判定は再生数だけでなく記事訪問、継続閲覧、報酬まで追う。広告リンクはテストでクリックしない。
