# ホームのストーリー横移動（2026-11-01）

## 課題と対応
横方向に続きがある一方、スクロールバーを非表示にしていたため、マウス利用者には移動手段が分からなかった。表示幅に収まりきらない場合に限って、左右に移動するボタンを追加。端では移動できない側を薄く表示し、ウィンドウ幅やスクロール位置に応じて更新する。動きを抑える設定を尊重し、キーボードからもボタンを操作できる。スマートフォンの横スワイプ、ストーリーを開閉する処理、記事へのリンクは変更しない。

## 再発防止
`tests/story_rail.browser.cjs` は実ブラウザで PC とスマートフォンの幅を開き、左右ボタンで端まで到達・戻れること、キーボード、開閉後のスクロール復元、タッチ移動を確認する。広告・計測ドメインの通信を遮断する。Playwright と Chrome が必要（CIには未組み込み）。例: ローカルを `npm run dev -- --hostname 127.0.0.1 --port 3184` で立ち上げ、Playwrightのある環境で `node tests/story_rail.browser.cjs`。必要なら `STORY_TEST_URL` と `CHROME_PATH` を設定。表示サイズ変更やストーリーの項目変更の際にも実行する。

今回、上記テストと `npx tsc --noEmit`、ローカルトップの読みやすさ検査（PC・スマホのライト／ダーク）が成功。公開後の結果は別途確認する。

ローカルの通常 `npm run build` はTurbopackが子プロセスのポートを開く際のOSエラーで完了せず、代わりに `npx next build --webpack` は型検査と637ページの生成を含め成功した。通常ビルドと本番デプロイが成功したと混同しない。
